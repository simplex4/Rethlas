# query-memory

Retrieve saved research before repeating a branch.

Search with search_memory(problem_id, query, channel, offset, limit). Queries are literal substrings, not semantic ranking; try distinctive short phrases and separate channels. Follow next_offset, then read_artifact through all text pages. Do not infer absence from a truncated preview. Preserve useful record IDs and distinguish unverified generation claims from reviewed candidates. Search recovered branch indexes as well as the latest checkpoint. Save substantive synthesis with record_artifacts, not repetitive retrieval logs.

Every MCP call requires the current access_key and run_id.
