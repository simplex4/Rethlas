# Search mathematical results

<!-- Adapted from agents/generation/.agents/skills/search-math-results/SKILL.md. -->

Use this skill for theorems, examples, constructions, counterexamples, or background. Read the target claim and relevant branch context. Read `turn.json`: `search_mode="live"` means external research is permitted; the configured built-in web search uses cached results under the managed policy, so this label does not promise live backend freshness. Obey the actual available capability and preserve retrieval dates/source dates when relevant. If search is disabled, use existing local references and reasoning only, recording retrieval as deferred. Do not substitute built-in search, another network client, or another account for disabled or denied access.

1. Read provided references and query existing research first.
2. When live search is permitted, run `python3 research.py theorem-search --query "COMPLETE MATHEMATICAL STATEMENT" --limit 5`. This is literature discovery, not evidence that a returned theorem is correct or applicable.
3. Inspect results for useful statements, constructions, proof methods, and obstructions. Refine the query if results are off-topic. If theorem search remains inadequate and built-in web search is available and permitted for this live turn, use it for related results, terminology, standard references, and constructions. Record queries, source URLs, and whether this fallback helped. If it is unavailable, record that limitation. Retrieve useful primary-source URLs with `python3 research.py download --url "HTTPS_URL" --name source.pdf`.
4. Keep originals and extracted text inside the workspace. Use `python3 research.py extract --file PATH_TO_PDF`; read the resulting text before relying on a paper. If extraction is unavailable, record the missing dependency without installing it. Plain-text and other supported references may be read directly. Record each reference as discovered-only, downloaded, extracted, or read, and identify the sections actually read. Downloading a paper or reading a search snippet is not reading or checking its theorem and proof; never promote reference status without completing the corresponding step.
5. Read both the theorem statement and its proof. Expand exact definitions and compare hypotheses, ambient objects, formulas, and quantifiers with the present setting. Extract techniques and constructions that can transfer, checking every changed hypothesis.
6. For partial results, identify their extra hypotheses, why their proofs need them, where the method fails without them, and the real obstruction exposed. Do not merely attempt to force applicability.
7. Persist useful findings using `python3 research.py append --channel events --file record.json`, including query, search intent, source title/URL, complete statement, paper id, theorem id, arXiv id when available, local paths, expanded definitions, applicability checks, partial-result analysis, proof insights, and relevant branch/subgoal ids. Do not invent missing identifiers.
8. If retrieval is unhelpful or unavailable, record attempted queries and exact limitations, and switch to independent research. Never repeat a denied request through an unsandboxed process.

Search results are useful only if they provide a relevant statement, adaptable construction or method, or concrete obstruction. Preserve provenance in downstream proof steps and the final draft, not merely in the search log.
